Параметры

Запас маски — единицы из 100, применяемые как 0.01·значение. Слайдеры «Маска» живут в FaceTracker.buildMask (expand/feather).

Как это работает
1. Выберите источник (файл — надёжнее всего; камера — чтобы сразу погонять маски на себе).
2. Включите 🧠 лица — загрузится MediaPipe FaceLandmarker (478 точек, офлайн из vendor/).
3. Режим маски: «только на лице» — эффект стреляет по лицу (маска/деформация), «кроме лица» — инвертированная маска (лицо нетронуто, фон плывёт).
4. ⏺ Запись сохраняет обработанное видео (.webm) со звуком экрана.

Ограничения: DRM-плееры (Кинопоиск, Netflix…) при захвате экрана дают чёрный кадр; чужие URL работают только если сервер отдаёт CORS-заголовки.
