# Кривое зеркало для видео (Crooked Mirror for Video)

Веб-приложение для применения реальных-time видеоэффектов к любому видео в браузере. Приложение захватывает экран с видео и применяет выбранные визуальные эффекты в реальном времени.

## Описание проекта

Это клиентское веб-приложение, которое позволяет пользователям:

- Захватывать экран с воспроизводимым видео (YouTube, локальные файлы и т.д.)
- Применять различные видеоэффекты в реальном времени
- Настраивать параметры эффектов
- Работать в полноэкранном режиме

### Технологии

- **Язык программирования**: JavaScript (ES6+)
- **Веб-API**:
    - MediaDevices.getDisplayMedia() для захвата экрана
    - Canvas API для обработки видео
    - Fullscreen API для полноэкранного режима
- **Без серверной части**: Все вычисления происходят в браузере пользователя

## Эффекты

Приложение поддерживает следующие эффекты:

1. **Волна (Wave)** - Кривое зеркало с настраиваемыми параметрами
    - Амплитуда X/Y
    - Длина волны X/Y
    - Скорость анимации
    - Опция центрирования волны

2. **Выпуклость (Bulge)** - Анимированный выпуклый эффект

3. **Инверсия цветов (Invert)** - Инверсия RGB-каналов

4. **Чёрно-белое (Grayscale)** - Преобразование в оттенки серого

5. **Зеркало (Mirror)** - Горизонтальное зеркалирование

6. **Пикселизация (Pixelate)** - Эффект пикселизации

7. **Твист (Twist)** - Закручивание изображения

8. **Рябь (Ripple)** - Эффект кругов на воде

## Развертывание

### Локальная разработка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/AmbAl28/crooked-mirror.git
cd crooked-mirror
```

2. Запустите локальный сервер (необходим для работы с MediaDevices API):

```bash
# Используя Python 3
python -m http.server

# Или используя Node.js
npx http-server

# Или используя Live Server в VS Code
```

3. Откройте `http://localhost:8000` в браузере

### Деплой на GitHub Pages

1. Зайдите в настройки вашего репозитория на GitHub
2. Выберите раздел "Pages"
3. В разделе "Source" выберите "Deploy from a branch"
4. Выберите ветку "main" и папку "/ (root)"
5. Нажмите "Save"

После этого ваше приложение будет доступно по адресу: `https://AmbAl28.github.io/crooked-mirror`

4. Настройте параметры:
    - Build command: (оставить пустым)
    - Publish directory: .
    - Root directory: (оставить пустым)

## Использование

1. Откройте видео в новой вкладке браузера (YouTube, Vimeo, локальный файл и т.д.)
2. Вернитесь на страницу приложения
3. Нажмите кнопку "Начать просмотр с эффектом"
4. Выберите вкладку с видео для захвата экрана
5. Выберите желаемый эффект из выпадающего списка
6. Для эффекта "Волна" настройте параметры в панели настроек
7. Используйте кнопку "⛶ Во весь экран" для переключения в полноэкранный режим

## Требования к браузеру

- Современный браузер с поддержкой:
    - MediaDevices.getDisplayMedia API
    - Canvas API
    - ES6+ JavaScript

Проверка совместимости:

- Chrome 72+
- Firefox 66+
- Safari 13+
- Edge 79+

## Особенности реализации

### Производительность

- Все вычисления происходят в основном потоке браузера
- Используется requestAnimationFrame для плавной анимации
- Эффекты применяются к каждому кадру видео через Canvas

### Безопасность

- Приложение не требует никаких разрешений кроме захвата экрана
- Все данные обрабатываются локально, не отправляются на сервер
- Нет использования сторонних библиотек или трекеров

### Ограничения

- Требуется HTTPS для работы с MediaDevices API (кроме localhost)
- Захват экрана работает только в активной вкладке браузера
- Производительность зависит от мощности устройства пользователя

## Разработка и поддержка

### Для AI-агентов

**Контекст проекта:**

- Это чисто клиентское приложение без бэкенда
- Основная логика находится в app.js (408 строк)
- UI реализован в index.html с встроенными стилями
- Все эффекты реализованы через манипуляции с ImageData в Canvas

**Архитектура:**

- Модульная структура с отдельными функциями для каждого эффекта
- Использование паттерна requestAnimationFrame для анимации
- Обработка событий DOM для взаимодействия с пользователем
- Динамическое обновление параметров эффектов в реальном времени

**Ключевые функции:**

- `applyEffect()` - основная функция цикла рендеринга
- `applyWaveEffect()` - самый сложный эффект с множеством параметров
- `stopCapture()` - корректная остановка захвата и очистка ресурсов
- `toggleFullscreen()` - управление полноэкранным режимом

**Рекомендации по развитию:**

- Оптимизировать производительность для высоких разрешений
- Добавить возможность сохранения обработанного видео
- Реализовать эффекты с использованием WebGL для лучшей производительности
- Добавить поддержку клавиатурных shortcuts
