# Crooked Mirror v3 — «кривое зеркало» для лиц

Веб-приложение: загружаете видеофайл / включаете камеру / транслируете вкладку с фильмом —
и все лица в кадре получают готовые безумные эффекты. **Всё считается локально в браузере**,
на сервер не уходит ни пикселя.

## Что умеет

### 🎭 21 готовый эффект для лиц — без слайдеров, «выбрал и смешно»
Улыбка Чешшир (кошачья пасть), Огромный рот, Микро-голова, Надутые щёки, Дыра-глазницы,
Выпучие глаза, Раздутое лицо, Голова-булавка, Вихрь внутри лица, Губы как у рыбы,
Тает как воск, Жуткое вытягивание, Лицо-гусеница, Завихрения, Желе-лицо, Лицо-шар,
Рябь по лицу, Зеркальное лицо, Карандашный набросок, Негатив, Пиксельная мозаика.
Все деформации привязаны к анатомическим точкам (зрачки, углы рта, кончик носа, щёки),
поэтому работают при любом ракурсе и движутся вместе с лицом.

### 😂 Эмодзи вместо лица
Выбранный эмодзи растягивается по контуру лица (клип по hull из 478 точек), под ним —
тёмная «пустота». Слайдер размера, лёгкая тряска по движению головы.

### 🎲 Рандом
- **Рандом эмодзи**: смена эмодзи при смене ракурса/композиции кадра (yaw/roll/масштаб лица)
  плюс страховка по таймеру — если лицо «застыло».
- **Рандом эффектов**: новый случайный лицевой эффект каждые N секунд (слайдер интервала).

### 🖼 Фото вместо лица
Кнопка «Фото» — любое изображение (своё лицо, кот, мем…) вставляется вместо лица и
обрезается по его контуру. Лицевые эффекты при этом применяются и к фото (улыбка Чешшир
надутым щекам кота — бесценно).

### Плюс из v2
- 8 ручных эффектов на весь кадр (волна, выпуклость, твист, рябь, пикселизация, зеркало,
  инверсия, ч/б) с выбором: на лице / кроме лица / по всему кадру;
- запись результата в `.webm` (со звуком экрана при захвате) и PNG-кадр;
- трекинг до 4 лиц со стабильными id, контуры по галочке;
- сворачиваемый интерфейс (кнопка ☰ или клавиша **H**) — ничего не мешает просмотру;
- политика приватности при входе + кнопка «ℹ️ О проекте».

## Технологии

| Слой | Что |
|---|---|
| Рендер | WebGL2, один фрагментный шейдер (warp по маске, clip-полигон слоя, blend-режимы) |
| Лица | MediaPipe FaceLandmarker, 478 точек + зрачки, делегат GPU/CPU, офлайн-бандл `vendor/` (~27 МБ) |
| Трекинг | nearest-by-center + EMA-сглаживание; детекция каждые 2 кадра на ≤480px |
| Источники | файл / экран (getDisplayMedia) / камера (getUserMedia) |
| Экспорт | canvas.captureStream + MediaRecorder (webm), toDataURL (PNG) |
| Приватность | никаких сетевых вызовов, кроме загрузки собственных файлов; consent-модалка при входе |

## Структура

```
index.html   # UI (шапка, панель настроек, модалки политики и «О проекте»)
app.js       # логика: источники, пресеты, эмодзи/фото, рандомы, запись
gl.js        # WebGL2-рендерер + шейдеры
faces.js     # FaceTracker: детекция, трекинг, фичи лица, rect/clip, маска
vendor/      # @mediapipe/tasks-vision + wasm + face_landmarker.task (офлайн)
firebase.json, .firebaserc, package.json   # деплой на Firebase Hosting
test-pw/     # e2e-тест (Playwright) — не деплоится
test-media/  # тестовые материалы — не деплоится
```

## Локальный запуск

```bash
python3 -m http.server 8000      # или: npx serve -l 8000
# http://localhost:8000
```

Камера/экран требуют `http://localhost` или HTTPS (политика браузеров).

## Публикация на Firebase

См. **ДЕПЛОЙ-FIREBASE.md** рядом — короткий путь: заменить id проекта в `.firebaserc`,
`npm i -g firebase-tools && firebase login && npm run deploy`.

## Тесты

```bash
cd test-pw && npm i playwright && npx playwright install chromium && node test-v3.js
```
E2E проверяет: consent-флоу, детекцию лица, анатомические фичи, rect/clip для эмодзи и фото,
каждый режим через readPixels (лицо деформируется, фон под маской — нет), рандом эмодзи при
смене ракурса, клип фото по контуру, сворачивание интерфейса (H), запись webm.

## Ограничения (честно)

- DRM-плееры (Кинопоиск, Netflix, YouTube Premium…) при захвате вкладки дают чёрный кадр —
  ограничение браузера, обходится только обработкой своих файлов.
- Warp-эффекты привязаны к наибольшему лицу в кадре (эмодзи/фото — тоже); маска «глаза-в-лице»
  и Poisson-блендинг фото — в дорожной карте.
- На very слабых устройствах: включится CPU-делегат, частота падёт (~15 fps) — это ожидаемо.
